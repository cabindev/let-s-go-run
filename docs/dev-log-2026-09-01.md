## 6) แก้บั๊กความปลอดภัย — Session ค้างสิทธิ์ ADMIN เดิมหลังถูกลดสิทธิ์

- **ต้นเหตุ**: `authOptions.ts` ใช้ JWT session strategy, เดิม `role` ถูกฝังใน token แค่ตอน login ครั้งแรก ไม่เคยเช็คซ้ำกับฐานข้อมูล — บัญชีที่เคยเป็น ADMIN แล้วถูกลดสิทธิ์เป็น USER แต่ session เก่ายังไม่หมดอายุ จะยังใช้สิทธิ์ ADMIN เดิมได้ต่อ (พบจริงกับบัญชี minichangmai ที่สร้างกิจกรรมได้ทั้งที่ role เป็น USER แล้ว)
- **แก้แล้ว**: เพิ่มการเช็ค role สดจาก DB ทุกครั้งที่ไม่ใช่ตอน sign-in ใน `jwt` callback
- **สถานะ: commit + push ขึ้น production แล้ว** (ไม่มี migration ใหม่)
- ทางแก้ระยะยาวเพิ่มเติมที่แนะนำแต่ยังไม่ทำ: เปลี่ยน `NEXTAUTH_SECRET` (สร้างค่าใหม่ไว้แล้วในเครื่อง local แต่**ยังไม่ได้เอาไปตั้งบน production**) — ตอนนี้เปลี่ยนแล้วจะทำให้ทุก session ที่ล็อกอินค้างอยู่หลุดหมด

## 7) ระบบเช็คอินรับเสื้อหน้างานด้วย QR — สรุปสุดท้าย: ทำผ่านเว็บมือถือ (CheckBIB)

ลองสถาปัตยกรรมมาแล้ว 2 แบบ **ใช้แบบที่ 2 จริง**:

### ❌ แบบแรก (ทำแล้วยกเลิก): โปรแกรม Python แยกต่างหาก
- เคยสร้างโปรเจกต์ `ludtong-checkin` (Python + OpenCV + pyzbar) รันบนโน้ตบุ๊กที่มีกล้อง เชื่อม API ของเว็บหลักผ่าน `CHECKIN_API_SECRET`
- ทดสอบผ่านกล้องจริงสำเร็จ แต่ผู้ใช้ต้องการให้ "สแกนด้วยมือถือได้เลย" ซึ่ง Python desktop app ทำแบบนั้นไม่ได้
- **ลบทิ้งทั้งหมดแล้ว**: ลบโฟลเดอร์ local, ลบ `/api/checkin/[id]/route.ts` และ `CHECKIN_API_SECRET` ออกจากเว็บหลัก (commit `baccc16`) — โค้ดยังอยู่บน GitHub (`cabindev/ludtong-checkin`) แต่ไม่ได้ใช้งานแล้ว รอผู้ใช้ตัดสินใจว่าจะลบ repo ทิ้งด้วยไหม

### ✅ แบบที่ใช้จริง: หน้า `/admin/checkin` ("CheckBIB") ในเว็บหลัก
- เปิดผ่านเบราว์เซอร์มือถือ ใช้กล้องมือถือสแกน QR ตรงๆ ผ่าน JS library `html5-qrcode` — ไม่ต้องติดตั้งอะไรเพิ่ม ใช้สิทธิ์แอดมินที่มีอยู่แล้ว ไม่ต้องพึ่ง secret key แยก
- สแกนแล้วโชว์การ์ดข้อมูลผู้สมัคร (ชื่อ, BIB, งาน, ประเภท, ไซส์เสื้อ, สถานะรับของ)
- เลือก **"รับที่บูธ"** → ให้ผู้สมัคร**เซ็นด้วยนิ้วบนจอ** (canvas) เป็นหลักฐาน → บันทึกรูปลายเซ็นไว้ที่ `Registration.pickupSignatureUrl`
- เลือก **"ส่งไปรษณีย์"** → กรอกเลขพัสดุได้ (ไม่บังคับ)
- ยืนยันแล้วขึ้นหน้าสรุปผล (โชว์ลายเซ็นที่เพิ่งเซ็น) พร้อมปุ่ม "สแกนต่อ" กลับไปสแกนคนถัดไปโดยกล้องไม่ต้องขอสิทธิ์ใหม่
- Schema เพิ่ม `Registration.pickupStatus`, `pickupAt`, `shippingTrackingNo`, `pickupSignatureUrl`
- หน้ารายการแอดมิน + Excel export โชว์สถานะรับของ + ลิงก์ดูลายเซ็น (ลิงก์ ไม่ได้ฝังรูปในไฟล์ กันไฟล์ใหญ่)
- **ทดสอบแล้วจริงจบครบ flow**: กล้องเปิดสำเร็จ, สแกน QR จากจอมือถือจริงได้, ดึงข้อมูลถูกต้อง, เซ็นลายเซ็น + ยืนยันบันทึกเข้า DB สำเร็จ, ตรวจสอบใน Excel export แล้วลิงก์ลายเซ็นถูกต้อง
- ไฟล์หลัก: `app/admin/checkin/page.tsx`, `components/admin/CheckinScanner.tsx`, `app/actions/admin.ts` (`lookupRegistrationForCheckin`, `confirmPickupAdmin`), `lib/checkin-qr.ts` (ใช้ร่วมกัน ไม่ได้ลบ)
- **สถานะ: commit + push ขึ้น production แล้วทั้งหมด** (migration ล่าสุด `add_pickup_signature` ต้องรันบน production ด้วย)
- **ข้อควรระวัง**: รูปลายเซ็นเก็บที่ `public/uploads/signatures/` บนดิสก์เซิร์ฟเวอร์ — ต้องเช็คว่า deploy process ของ Plesk ไม่ลบโฟลเดอร์ `public/uploads/` ทิ้งทุกครั้งที่ deploy ใหม่

### ✅ แก้ช่องโหว่แล้ว: QR ไม่แสดงสำหรับงานฟรี
- เพิ่ม QR + BIB ในหน้ารายละเอียดกิจกรรม (`/events/[id]`, `/virtual/[id]`) ตรงจุดที่โชว์สถานะการสมัครอยู่แล้ว — ครอบคลุมทั้งงานฟรีและงานที่มีค่าสมัคร (งานมีค่าสมัครยังเห็น QR ที่หน้าจ่ายเงินได้เหมือนเดิมด้วย)
- ทดสอบแล้วกับงานฟรีจริง ยืนยันว่า QR ขึ้นถูกต้อง

## งานที่ต้องทำต่อ (ค้างอยู่ ณ สิ้นวัน)

1. **เปลี่ยน `NEXTAUTH_SECRET` บน production** — สร้างค่าใหม่ไว้ในเครื่อง local แล้ว แต่ยังไม่ได้เอาไปตั้งบนเซิร์ฟเวอร์จริง (ค่าเดิมยังเป็น `"secret"` ซึ่งเดาง่ายมาก) การเปลี่ยนจะทำให้ทุกคนหลุด session ต้องล็อกอินใหม่
2. **รัน `prisma migrate deploy` บน production** ให้ทันโค้ดล่าสุด (มี migration ค้างหลายตัวจากวันนี้ รวมถึง `add_pickup_signature`)
3. **ตัดสินใจเรื่อง GitHub repo `cabindev/ludtong-checkin`** — จะลบทิ้งหรือเก็บไว้เป็นอ้างอิงเฉยๆ (ไม่ได้ใช้งานแล้ว)
4. **เปลี่ยนรหัส/secret ทั้งหมดที่เคยแปะในแชทระหว่างพัฒนา** — root SSH password, Stripe live secret key, Google OAuth client secret, SMTP app password (ยังไม่ได้ทำ ควรทำโดยเร็วที่สุด)
5. ทดสอบหน้า CheckBIB บนมือถือจริงอีกครั้งกับหลายๆ คน ก่อนวันงานจริง เพื่อความมั่นใจเรื่องความเร็ว/ความเสถียรตอนมีคนต่อคิว
